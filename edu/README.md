# 온라인 교육 이수 (edu)

지정한 교육 영상을 직원이 보고, **실제로 본 만큼 진도가 쌓여** 자동으로 이수
처리되는 앱입니다. 담당자는 이수율과 아직 안 들은 사람을 바로 봅니다.

| | |
|---|---|
| 서비스 ID | `edu` |
| 접속 주소 | `/edu/` · 담당자 화면 `/edu/admin` |
| 컨테이너 | `demo-edu` (안쪽 포트 8080, 바깥 포트 열지 않음) |
| 데이터 | `/data/app.db` · 업로드 자료 `/data/uploads/` |

---

## 왜 만들었나

전 직원 교육을 돌릴 때 유료 온라인 강의를 사면, **안 듣는 사람 몫이 그대로
매몰비용**이 됩니다. 그날 출장·휴가·장애 대응이 겹치는 사람이 반드시 나오고,
그 인원만큼 돈이 날아가면서 교육 목표도 미달합니다.

기초 과정은 무료 강의가 이미 충분히 좋습니다. 무료로 바꿀 때 잃는 것은
콘텐츠가 아니라 **수강 기록** 하나입니다. 이 앱은 그 기록만 회사가 갖게 합니다.

## 진도를 어떻게 재는가

영상은 이 앱이 내보내지 않습니다. 유튜브가 재생하고, 화면이 5초마다 보내오는
**재생 위치**만 받아 적습니다. 그래서 몇 명이 붙어도 서버 부하가 사실상 없습니다.

영상을 10초짜리 칸으로 쪼개서 **실제로 지나간 칸만** 채웁니다.

| 어떻게 보든 | 결과 |
|---|---|
| 정상 재생 | 칸이 순서대로 채워짐 → 90% 넘으면 자동 이수 |
| 1.5배·2배속 | 그대로 인정 (5초에 10초를 가도 이어 본 것으로 봄) |
| 스크롤바를 맨 뒤로 끌기 | **중간 칸이 비어 이수되지 않음** |
| 띄엄띄엄 여러 번 끌기 | 마찬가지로 채워지지 않음 |

최대 위치만 기록하면 스크롤바 한 번으로 끝나 버립니다. 칸을 세는 이유가
그것입니다. 직전 보고 위치와 지금 위치의 차이가 정상 재생 범위(30초) 안일
때만 그 사이를 본 것으로 인정합니다.

기준은 차시마다 바꿀 수 있고 기본은 90%입니다. 100%로 두지 않는 이유는
유튜브 영상 끝의 엔딩 카드까지 보는 사람이 드물어서, 다 본 사람이 미이수로
남기 때문입니다.

**보던 곳부터 이어서 재생됩니다.** 진도를 재고 있으면서 처음부터 틀 이유가
없습니다. 15초 미만이거나 거의 끝까지 본 경우에만 처음부터 시작하고,
이어보기로 건너뛴 구간은 본 것으로 세지 않습니다.

## 영상이 아닌 차시

사내 자료(PPT를 PDF로 변환한 것)와 바깥 링크는 진도를 잴 방법이 없어
**"다 봤습니다" 버튼**으로 처리합니다. 그래서 이수 판정의 알맹이는 영상 차시가
지도록 구성하는 편이 좋습니다.

---

## 로그인 — 두 가지 방식, 환경변수 하나

`.env` 의 `AUTH_MODE` 로 갈립니다. **두 방식이 같은 모양의 사용자 정보를 만들어
내므로 나머지 코드는 어느 쪽인지 알지 못합니다.**

| | `AUTH_MODE=portal` | `AUTH_MODE=standalone` |
|---|---|---|
| 누가 확인하나 | 앞단의 챗 포털 | 이 앱이 직접 |
| 무엇으로 | 포털 로그인 → `X-User-*` 헤더 | 아이디(또는 사번) + 비밀번호 |
| 담당자 판정 | 포털 관리자 화면의 서비스 담당자 | 명단의 담당자 표시 |
| 접속 주소 | `/edu/` | `http://서버:포트/` |

포털이 아직 전 직원에게 열리지 않은 회사에서는 단독으로 먼저 돌리고, 포털이
열리면 `AUTH_MODE` 만 바꿔 붙일 수 있게 두 갈래를 만들었습니다. 사번이 아니라
**포털 계정 아이디를 열쇠로 쓰기 때문에** 옮겨도 그동안의 이수 기록이 이어집니다.

단독 모드에서는 아이디를 여러 번 틀리면 10분간 잠기고, 없는 아이디와 틀린
비밀번호를 **구분해서 알려주지 않습니다**(아이디만 넣어 보고 재직 여부를
알아내는 것을 막습니다). 비밀번호는 원문을 저장하지 않고 사람마다 다른 소금을
섞어 20만 번 돌린 해시만 남깁니다.

## 대상자 명단

이수율과 미수강자 명단은 **'들어야 할 사람' 전체**가 있어야 나옵니다.
담당자 화면에서 세 가지 방법 중 하나로 넣습니다.

1. **파일로 올리기** — CSV·엑셀. 열 이름은 `사원번호`·`성명`·`소속` 처럼 달라도
   알아봅니다. 엑셀이 사번을 `1002.0` 으로 저장한 것도 정리하고, 사번이 겹치면
   **어느 사번인지 알려주고 멈춥니다**
2. **포털에서 가져오기** — 포털의 직원 명단을 그대로 받아 옵니다
3. **한 명씩** — 신규 입사자용. 각 줄 [수정] 으로 이름·부서·사번·재직 여부를 고칩니다

명단을 다시 올려도 **담당자 지정·비밀번호·사번은 유지됩니다.** 올릴 때마다
담당자가 날아가면 아무도 관리자 화면에 못 들어가는 순간이 생기고, 비밀번호가
초기화되면 이미 바꾼 사람이 못 들어옵니다.

아이디는 고치지 않습니다 — 진도 기록을 잇는 열쇠라 바꾸면 그동안의 이수
기록이 끊깁니다. 퇴사자는 지우지 말고 재직 체크만 풀면 로그인은 막히고
기록은 남습니다.

## 담당자 화면

* 이수율 · 대상 인원 · 이수 완료 · 듣는 중 · 미시작 · 마감 D-day
* 부서별 이수율, 차시별 완료 인원
* 사람별 표 — 아이디·사번·이름·부서·상태·시청률·완료 차시·이수일시
* 검색(아이디·이름·부서·사번)과 부서 필터
* **CSV 는 지금 걸러 놓은 조건 그대로** 내려받습니다. '미시작' + 부서를 골라
  놓고 누르면 그 부서 미수강자만 담긴 파일이 나오고, 파일 이름에도 남습니다

'차시 완료 수'와 '시청률'을 따로 보여 줍니다. 독촉 메일을 보낼 때 아직
시작도 안 한 사람과 거의 다 본 사람은 다르게 다뤄야 하기 때문입니다.

## 챗에 붙이기

`portal/app/tools/edu.py` 가 도구 두 개를 등록합니다.

* 직원 — "나 교육 들어야 해?" → 남은 차시와 마감일
* 담당자 — "교육 이수율 얼마야", "아직 안 들은 사람 누구야" → 이수율·미수강자

포털은 이수 여부를 직접 계산하지 않습니다. edu 에게 물어보고 답을 옮깁니다.
같은 계산이 두 벌이 되면 화면과 챗이 다른 숫자를 말하는 일이 생깁니다.

## 실행

레포 루트에서 `./demo.sh` (또는 `.\demo.ps1`) 를 돌리면 다른 앱과 함께 뜹니다.
가짜 교육 자료는 `app/seed_demo.py` 가 넣습니다 — **DB 에 직접 쓰지 않고**
실제 재생을 흉내 내어 `record_watch` 를 반복 호출하므로, 자료가 보인다는 것
자체가 칸 채우기·이수 판정이 돌고 있다는 확인이 됩니다.

이 앱만 다시 띄우려면:

```bash
./deploy.sh edu
docker exec -i demo-edu python -m app.seed_demo --force   # 자료를 다시 넣을 때만
```

> 체험판의 영상은 **바깥 유튜브 공개 영상**입니다. 게시자가 내리면 재생되지
> 않으므로, 그때는 담당자 화면에서 차시 [수정] 으로 다른 주소를 넣으면 됩니다.
> 영상을 바꾸면 그 차시의 진도는 초기화됩니다 — 옛 영상에서 본 만큼이 새 영상
> 진도로 둔갑하는 것을 막기 위해서입니다.

## 환경변수

| 이름 | 설명 |
|---|---|
| `AUTH_MODE` | `portal`(기본) 또는 `standalone` |
| `PORTAL_API_URL` | 챗 포털 주소. 서비스 자동 등록·이력 전송에 씁니다 |
| `AUDIT_TOKEN` | 포털과 나눠 갖는 서비스 토큰 |
| `ADMIN_IDS` | 단독 모드에서 맨 처음 담당자 아이디 |
| `DEFAULT_PASSWORD` | 단독 모드에서 계정을 만들 때 넣는 초기 비밀번호 |
| `PASSWORD_MIN_LEN` | 새 비밀번호 최소 길이 (기본 1 — 사실상 제한 없음) |
| `SESSION_HOURS` · `SECRET_KEY` · `COOKIE_SECURE` | 단독 모드 로그인 쿠키 |
| `DEV_MODE` | 개발용. 배포에서는 false |
| `MAX_UPLOAD_MB` | 업로드 PDF 최대 크기 (기본 30) |

## API 목록

`user` = 접속이 확인된 사람 누구나 · `admin` = 교육 담당자

| 메서드 | 경로 | 권한 | 하는 일 |
|---|---|---|---|
| GET | `/api/health` | 없음 | 앱이 켜졌는지 확인 |
| POST | `/api/login` · `/api/logout` | 없음 | 단독 모드 로그인 |
| GET | `/api/me` · `/api/config` | user | 접속자 정보 · 화면 설정 |
| POST | `/api/me/password` | user | 본인 비밀번호 변경 |
| GET | `/api/courses` | user | 나에게 지정된 과정과 내 진도 |
| GET | `/api/status` | user | 내 이수 상태 한 문장 (챗에서 사용) |
| POST | `/api/progress` | user | 재생 위치를 받아 진도 기록·이수 판정 |
| POST | `/api/lessons/{id}/done` | user | 자료·링크 차시 열람 완료 |
| GET | `/files/{name}` | user | 업로드된 자료(PDF) 열람 |
| GET/POST/PATCH/DELETE | `/api/admin/courses…` | admin | 과정·차시 관리 |
| POST | `/api/admin/upload` | admin | 자료 PDF 업로드 |
| GET/POST/PATCH/DELETE | `/api/admin/roster…` | admin | 대상자 명단 · 담당자 지정 · 비밀번호 초기화 |
| GET | `/api/admin/stats?courseId=` | admin | 이수율·부서별·사람별 현황 |
| GET | `/api/admin/summary` | admin | 과정별 이수율 한 문장 (챗에서 사용) |
| GET | `/api/admin/export?courseId=` | admin | 이수 현황 CSV (`status`·`dept`·`q` 로 걸러서) |
| GET | `/api/admin/audit` | admin | 이 앱에 남은 이력 |
