# IT Asset Portal

## 프로젝트 목적

사내 IT 자산을 통합 관리하기 위한 웹 포털

현재 Excel로 관리 중인 자산, IP, 렌탈, 라이선스 정보를 웹 기반으로 관리한다.

---

## 사용자 권한

### ADMIN

- 사용자 관리
- 직원 관리
- 자산 등록/수정/삭제
- IP 관리
- 라이선스 관리
- 렌탈 관리
- CSV Import
- Excel Export

### USER

- 조회만 가능
- 자산 조회
- 직원 조회
- IP 조회
