========================================
 미르 IT 매뉴얼 포털 - 사용 안내
========================================


[1] 폴더 구조
--------------------------------------------------

  IT매뉴얼포털/
    index.html            <- 포털 본체. 건드릴 일 없습니다.
    data/
      manuals.js          <- 모든 글 내용이 들어있는 파일
    images/
      hancom/*.jpg        <- 한컴오피스 설치 매뉴얼 이미지
      kaspersky/*.jpg     <- 카스퍼스키 관리 툴 매뉴얼 이미지
      sample-*/*.jpg      <- 샘플 매뉴얼 이미지
    README.txt            <- 이 파일

  * 이 폴더는 통째로 하나입니다. 옮기거나 복사할 때 폴더째로 하세요.
  * index.html 혼자 떼어내면 내용이 안 나옵니다.


[2] 사내 웹서버에 올리기
--------------------------------------------------

  폴더 전체를 웹서버에 그대로 올리면 끝입니다.
  예) http://내부주소/manual/  로 접속

  별도 설치나 프로그램 없이 동작합니다.
  (서버 없이 index.html을 더블클릭해도 열립니다)


[3] 내용 고치기 - 편집 모드
--------------------------------------------------

  1. 포털 오른쪽 위 [편집 모드] 클릭
  2. 고치고 싶은 글자를 그냥 클릭해서 수정
     - 매뉴얼 제목, 항목 이름, 설명 줄, 문의 안내 모두 가능
  3. 순서 바꾸기: 왼쪽 ⠿ 표시를 마우스로 눌러서 끌기
     - 매뉴얼끼리 / 항목(Menu)끼리 / 설명 줄끼리 / 이미지끼리
  4. 추가·삭제 버튼
     - [+ 새 매뉴얼 추가]   목록 화면 맨 끝
     - [+ 새 항목(Menu) 추가]
     - [+ 설명 줄] [+ 이미지] [묶음 삭제]
  5. 다 하면 오른쪽 위 [저장 (manuals.js 받기)] 클릭
     -> manuals.js 파일이 다운로드됨
  6. 받은 manuals.js 를 서버의 data/ 폴더에 덮어쓰기

  ※ 6번을 해야 실제로 반영됩니다.
     저장 버튼만 누르고 덮어쓰지 않으면 그 화면에서만 바뀐 상태입니다.


[4] 이미지 크기 조절
--------------------------------------------------

  오른쪽 위 [작게] [보통] [크게] 버튼으로 바로 바꿉니다.

    작게 : 훑어볼 때. 이미지가 옆으로 나란히 붙어 한 화면에 많이 들어감
    보통 : 기본값. 대부분 이 상태가 적당함
    크게 : 화면을 자세히 봐야 할 때

  * 이미지는 '높이'를 기준으로 맞춰집니다.
    그래서 세로로 긴 메뉴 캡처가 화면을 다 잡아먹지 않고,
    가로로 긴 표와 비슷한 크기로 나란히 놓입니다.
  * 보는 사람마다 선택이 브라우저에 기억됩니다.
  * 편집 모드에서 크기를 고르고 [저장]하면 그게 전체 기본값이 됩니다.
  * 특정 이미지 하나만 다르게 하고 싶으면
    편집 모드 -> 그 이미지 위 [기본] 버튼을 눌러
    기본 → 작게 → 보통 → 크게 → 원본 순으로 바꾸면 됩니다.
  * 어떤 크기든 이미지를 클릭하면 전체화면으로 크게 볼 수 있습니다.

  [스크롤 버튼]
  페이지가 길 때 오른쪽 아래에 ▲ ▼ 버튼이 나타납니다.
    ▲ 맨 위로   ▼ 맨 아래로
  갈 수 있는 방향만 보이고, 짧은 페이지에서는 나타나지 않습니다.
  이동 중에 마우스 휠을 굴리면 멈춥니다.


[5] 이미지 추가하기
--------------------------------------------------

  권장 방법 (파일이 가벼움):
    1. 이미지를 images/<매뉴얼폴더>/ 안에 넣는다
       예) images/hancom/새화면.jpg
    2. 편집 모드에서 [+ 이미지] -> [취소] 선택
    3. 경로 입력: hancom/새화면.jpg

  간단한 방법:
    [+ 이미지] -> [확인] -> 내 PC에서 파일 선택
    ※ 이 경우 이미지가 manuals.js 안에 통째로 들어가서
       파일이 커집니다. 몇 장 정도만 이 방법을 쓰세요.


[6] 매뉴얼을 더 추가하려면
--------------------------------------------------

  pptx 파일을 그대로 전달해 주시면
  텍스트와 이미지를 자동으로 분리해서 넣어드립니다.

  - 슬라이드의 설명 글은 웹 글자로
  - 캡처 화면은 이미지 파일로 (빨간 강조 표시 그대로 유지)
  - 설명이 이미지에도 있고 글에도 있는 중복 없음

  직접 하시려면 편집 모드에서 [+ 새 매뉴얼 추가] 후
  항목과 설명을 채우고, 이미지는 [4]번 방법으로 넣으시면 됩니다.


[6] 참고
--------------------------------------------------

  - 설명 줄 번호는 항목 안에서 자동으로 1,2,3... 매겨집니다.
    중간에 줄을 넣거나 지워도 번호는 알아서 다시 매겨집니다.
  - 이미지를 클릭하면 크게 볼 수 있습니다. (보기 모드에서만)
  - 주소에 https:// 로 시작하는 글자는 자동으로 링크가 됩니다.
  - manuals.js 는 메모장으로 열어서 직접 고쳐도 됩니다.
    (구조가 익숙하시면 대량 수정할 때 더 빠릅니다)
