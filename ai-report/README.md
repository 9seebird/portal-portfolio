# AI 이용 현황 대시보드 (사내 배포용)

웍스AI 사용량 엑셀을 웹 대시보드로 보여주는 앱입니다.
기존 `ai-report` 서비스의 화면을 새 대시보드로 교체한 버전입니다.

---

## 이번에 바뀐 것

| | 기존 | 새 버전 |
|---|---|---|
| 첫 화면 | 월별 카드 → 클릭 시 상세 | 월별 카드 → 클릭 시 상세 (그대로 유지) |
| 화면 | 서버(pandas)에서 계산한 표 | 브라우저에서 직접 엑셀을 읽어 그리는 대시보드 |
| 입력 파일 | Raw Data 엑셀만 | Raw Data + 웍스AI 집계 엑셀 둘 다 |
| 사용자 순위 | 전체 | 전체 (INPUT/OUTPUT 토큰·요금 분리, 활동일수, 모델·도구 드릴다운) |
| 외부망 | 불필요 | 불필요 (엑셀 파싱 라이브러리를 index.html 안에 내장) |

**포탈 로그인 · 업로드 권한 · 감사 로그 · 포트(8081) · 주소는 그대로입니다.**
기존 API(`/api/files`, `/api/upload`, `/api/data`, `/api/preview`, `/api/logs`)도 전부 살아 있습니다.

---

## 배포 방법

### 1. 파일 교체

서버의 `~/services/ai-report` 폴더에서 아래 두 파일만 덮어씁니다.

- `index.html`  ← 새 대시보드 (엑셀 파싱 라이브러리 내장, 약 930KB)
- `main.py`     ← 엑셀 원본을 내려주는 `/api/file/{filename}` 엔드포인트 추가

`Dockerfile`, `docker-compose.yml`, `data/` 는 **바꾸지 않습니다.**

```bash
cd ~/services/ai-report

# 되돌릴 수 있게 백업
cp index.html index.html.bak
cp main.py    main.py.bak

# (SFTP로 새 index.html, main.py 업로드한 뒤)
```

### 2. 재빌드 후 실행

```bash
cd ~/services/ai-report
sudo docker compose up -d --build
```

`--build` 가 꼭 필요합니다. `index.html` 과 `main.py` 는 이미지 안으로 COPY 되기 때문에
`docker compose restart` 만으로는 반영되지 않습니다.

### 3. 확인

```
http://10.20.10.10:8081        (컨테이너 직접)
http://10.20.10.10/ai-report/  (nginx 경유)
```

> **브라우저 캐시**: 화면이 그대로면 `Ctrl` + `Shift` + `R` 로 강력 새로고침 하세요.
> nginx 뒤 서브패스(`/ai-report/`)에서도 API를 알아서 찾아갑니다.
> 그래도 업로드 화면만 나온다면 `F12` → Console 에 `[AI리포트]` 경고가 찍히고,
> 화면에도 어떤 주소가 응답하지 않는지 표시됩니다. 그 경로를 nginx가
> ai-report 컨테이너로 넘기고 있는지 확인해주세요.

- 첫 화면에 `data/` 폴더의 엑셀이 **월별 카드**로 뜹니다. 카드를 누르면 그 달 상세로 들어갑니다.
- 상세 화면 상단의 **[목록]** 버튼으로 카드 화면으로 돌아오고, 옆 드롭다운으로 바로 다른 달로 전환할 수 있습니다.
- `data/` 폴더에 SFTP로 엑셀을 직접 넣어도 됩니다. 새로고침하면 카드가 자동으로 생깁니다. (업로드 불필요)
- 포탈에 로그인한 상태면 버튼이 **[서버에 업로드]** 로 바뀌고, 올린 파일이 `data/` 에 저장됩니다.
- 포탈 관리자면 드롭다운 옆에 **삭제(휴지통)** 버튼이 보입니다.
- 로그인하지 않았으면 버튼이 **[엑셀 열기]** 가 되고, 고른 파일을 서버에 저장하지 않고 브라우저에서만 봅니다.

### 4. 되돌리기

```bash
cd ~/services/ai-report
cp index.html.bak index.html
cp main.py.bak    main.py
sudo docker compose up -d --build
```

---

## 매달 하는 일

1. 웍스AI에서 **Raw_Data** 엑셀을 그 달 1일 ~ 말일로 받는다
2. 대시보드에서 **[서버에 업로드]** (또는 `data/` 폴더에 직접 복사)
3. 끝. 드롭다운에 자동으로 잡힙니다

> 웍스AI 집계는 "어제까지" 기준이라, 그 달 데이터를 온전히 받으려면 **다음 달 1일 이후**에 받으세요.

## 파일별 역할

```
ai-report/
├── index.html          새 대시보드 (단일 파일, 라이브러리 내장 → 외부망 불필요)
├── main.py             FastAPI 백엔드 (포탈 인증 · 업로드 · 감사로그 · 엑셀 API)
├── Dockerfile          변경 없음
├── docker-compose.yml  변경 없음 (8081 → 8080, ./data 볼륨)
└── data/               엑셀 보관 폴더 (볼륨으로 마운트되어 컨테이너 재빌드에도 유지)
```

### index.html 만 따로 쓰기

`index.html` 은 그 자체로 완전한 단일 파일입니다.
서버 없이 PC에서 더블클릭해도 동작하고, 이때는 서버 드롭다운 없이 내 PC 엑셀만 열어봅니다.
